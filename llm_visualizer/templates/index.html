How It Works (v3)

Unlike v2 which matched tokens to template points, v3 fits a continuous curve and selects only tokens that actually lie on it.

1. Aligns curve to token cloud (multi-start ICP)

2. Measures distance from every token to the continuous polyline

3. Keeps only tokens within a tight threshold (inliers)

4. Iteratively refines: re-aligns curve to inliers

5. Orders tokens along the curve, prunes isolated ones

Try: Helix + Years, Line + Numbers, Circle + Months
